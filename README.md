# 🚀 Job Tracker App

A Django-based web application to track job applications, manage follow-ups, and generate AI-based cover letters.

---

## 🔥 Features

- ✅ User Authentication (Login/Register)
- ✅ Job Tracking (CRUD)
- ✅ Follow-up Reminder System
- ✅ AI Cover Letter Generator
- ✅ Clean UI with Bootstrap

---

## 🛠️ Tech Stack

- Python
- Django
- SQLite
- Bootstrap
